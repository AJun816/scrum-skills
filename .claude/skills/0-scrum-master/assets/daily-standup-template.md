# 每日站会模板

## 模板说明
每日站会是敏捷团队的核心仪式，用于快速同步团队进展、识别障碍、保持团队协作。

## 使用场景
- 每个工作日固定时间举行
- 时长控制在15分钟内
- 全体开发团队成员参与
- Scrum Master主持并记录障碍
