# 技能优化指南

## 何时优化技能

1. **使用后发现问题**
   - 工作流程不清晰
   - 缺少必要的说明
   - 协作机制不完善

2. **项目需求变化**
   - 技术栈升级
   - 业务域扩展
   - 团队角色调整

3. **性能优化**
   - Token消耗过高
   - 响应速度慢
   - 缓存机制不完善

4. **文件大小超标**
   - SKILL.md 超过 800行
   - 需要拆分到 references/

## 优化方法

### 1. 优化 SKILL.md

**文件大小控制：**
- 保持 SKILL.md 在 400-500行
- 详细内容移到 references/
- 模板移到 assets/
- 脚本移到 scripts/

**内容优化：**
- 补充缺失的说明
- 优化工作流程描述
- 完善协作机制
- 添加强制检查点

### 2. 添加资源文件

**references/ 文档：**
- 详细的工作流程
- 编码规范
- 最佳实践
- 示例参考

**assets/ 模板：**
- 文档模板
- 配置模板
- 代码模板

**scripts/ 脚本：**
- 自动化脚本
- 工具脚本

### 3. 优化缓存机制

**识别高频读取内容：**
- 项目配置
- 业务规则
- API文档

**设计合理的缓存结构：**
- 按模块分类
- 按优先级排序
- 定期更新

**实现增量更新逻辑：**
- 使用 git diff 识别变更
- 只读取变更的文件
- 更新缓存元数据

## 使用技能创建器优化

### 优化现有技能

```
@7-skill-creator 帮我优化 {技能名称} 技能
```

说明需要优化的方面，技能创建器会帮你改进。

### 重构超标文件

```
@7-skill-creator 帮我重构 {技能名称}，文件超过800行了
```

技能创建器会自动拆分文件，将详细内容移到 references/。
