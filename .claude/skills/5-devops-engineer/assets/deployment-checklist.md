# 部署检查清单

## 部署前检查

### 代码质量
- [ ] 代码已通过评审
- [ ] 单元测试全部通过
- [ ] 集成测试全部通过
- [ ] 代码覆盖率达标

### 环境准备
- [ ] 目标环境可用
- [ ] 数据库备份完成
- [ ] 配置文件已更新
- [ ] 依赖服务正常

### 部署计划
- [ ] 部署时间已确认
- [ ] 回滚方案已准备
- [ ] 相关人员已通知
- [ ] 监控已配置

## 部署中检查

- [ ] 服务停止成功
- [ ] 代码部署完成
- [ ] 数据库迁移成功
- [ ] 服务启动成功
- [ ] 健康检查通过

## 部署后验证

- [ ] 核心功能验证
- [ ] 性能指标正常
- [ ] 日志无异常
- [ ] 监控数据正常
- [ ] 用户反馈正常

## 回滚条件

如出现以下情况，立即回滚：
- 核心功能不可用
- 严重性能问题
- 数据丢失或损坏
- 安全漏洞
