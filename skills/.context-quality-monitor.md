# 上下文质量监控和Token优化机制

**本文件定义技能组如何监控上下文长度，防止AI幻觉，确保最高质量回复**

## 🚨 核心理念

当对话上下文过长时，AI的回复质量会下降，可能出现：
- 遗忘早期对话内容
- 回答不准确或出现幻觉
- 响应速度变慢
- 理解偏差增加

**解决方案：主动监控上下文长度，及时提醒用户重启对话窗口。**

## 📊 质量监控标准

### Token使用阈值

**根据模型能力设定阈值：**

```yaml
# 在 PROJECT_CONFIG.md 中配置
context_quality_config:
  model: "claude-sonnet-4-5"  # 当前使用的模型
  max_context_tokens: 200000   # 模型最大上下文

  # 质量阈值（基于实际使用经验）
  thresholds:
    optimal: 50000      # 最佳质量区间 (0-50K tokens)
    good: 100000        # 良好质量区间 (50K-100K tokens)
    acceptable: 150000  # 可接受区间 (100K-150K tokens)
    warning: 180000     # 警告区间 (150K-180K tokens)
    critical: 200000    # 临界区间 (180K-200K tokens)

  # 自动提醒配置
  auto_reminder:
    enabled: true
    reminder_at_warning: true   # 达到警告阈值时提醒
    reminder_at_critical: true  # 达到临界阈值时强烈建议重启
```

### 质量评估标准

**不同Token区间的质量特征：**

| Token区间 | 质量等级 | 特征 | 建议 |
|----------|---------|------|------|
| 0-50K | ⭐⭐⭐⭐⭐ 最佳 | 响应快速、准确度高、无遗忘 | 正常使用 |
| 50K-100K | ⭐⭐⭐⭐ 良好 | 响应正常、准确度高、偶尔需要提醒 | 正常使用 |
| 100K-150K | ⭐⭐⭐ 可接受 | 响应稍慢、可能需要多次提醒、建议定期总结 | 考虑重启 |
| 150K-180K | ⭐⭐ 警告 | 响应变慢、可能遗忘早期内容、准确度下降 | **建议重启** |
| 180K-200K | ⭐ 临界 | 响应很慢、频繁遗忘、准确度明显下降 | **强烈建议重启** |

### Token估算方法

**由于无法直接获取精确Token数，使用估算方法：**

```python
# 估算公式（基于经验）
estimated_tokens = (
    conversation_turns * 1000 +      # 每轮对话约1000 tokens
    code_blocks * 500 +               # 每个代码块约500 tokens
    file_reads * 2000 +               # 每次文件读取约2000 tokens
    long_responses * 1500             # 每个长回复约1500 tokens
)
```

**更精确的估算：**

### 检查代码示例

**技能如何检查上下文质量：**

```python
def check_context_quality():
    """检查上下文质量"""
    # 1. 读取配置
    config = read_project_config()
    monitoring = config.get('context_quality_monitoring', {})

    if not monitoring.get('enabled', True):
        return  # 监控未启用

    # 2. 估算当前Token使用
    estimated_tokens = estimate_current_tokens()

    # 3. 判断质量等级
    thresholds = monitoring.get('thresholds', {})
    quality_level = get_quality_level(estimated_tokens, thresholds)

    # 4. 显示提醒（如果需要）
    if quality_level in ['warning', 'critical']:
        show_quality_reminder(quality_level, estimated_tokens)

    # 5. 更新统计信息
    update_statistics(estimated_tokens)
```

**向用户说明重启的好处：**

1. **恢复最佳性能**：新对话窗口从0开始，AI处于最佳状态
2. **提高准确度**：避免遗忘和混淆，回答更准确

4. **防止幻觉**：降低AI编造信息的风险
