# Bug分类和严重程度评估指南

## Bug类型分类

### 1. 前端Bug

**特征识别：**
- 错误发生在浏览器控制台
- UI显示异常、布局错乱
- 用户交互无响应或响应错误
- JavaScript运行时错误

**常见错误：**
- `TypeError: Cannot read property 'xxx' of undefined`
- `ReferenceError: xxx is not defined`
- `Vue warn: xxx`
- CSS样式问题
- 路由跳转异常

**分配给：** `4-vue-frontend-dev` 或 `4-frontend-design`

### 2. 后端Bug

**特征识别：**
- API返回错误状态码（500, 400等）
- 后端日志中有异常堆栈
- 业务逻辑处理错误
- 数据处理异常

**常见错误：**
- `NullPointerException`
- `IllegalArgumentException`
- `SQLException`
- 业务规则验证失败
- 数据转换错误

**分配给：** `4-java-backend-dev`

### 3. 数据库Bug

**特征识别：**
- SQL执行错误
- 数据一致性问题
- 查询性能问题
- 数据丢失或损坏

**常见错误：**
- SQL语法错误
- 外键约束违反
- 死锁
- 索引缺失导致慢查询

**分配给：** `4-java-backend-dev`（数据层）

### 4. 集成Bug

**特征识别：**
- 第三方API调用失败
- 外部服务超时
- 数据格式不匹配

**常见错误：**
- PropellerAds API调用失败
- Skro追踪器集成问题
- 网络连接超时

**分配给：** `4-java-backend-dev`（适配器层）

### 5. 配置Bug

**特征识别：**
- 环境配置错误
- 参数配置不正确
- 部署配置问题

**常见错误：**
- 数据库连接配置错误
- API密钥配置错误
- 端口冲突

**分配给：** `5-devops-engineer`

## 严重程度评估

### P0 - 紧急（Critical）

**定义：** 系统核心功能完全不可用，影响所有用户

**示例：**
- 系统无法启动
- 数据库连接失败，所有API不可用
- 严重的数据丢失或损坏
- 安全漏洞导致数据泄露

**处理时效：** 立即处理，2小时内修复

**处理方式：**
- 立即组织紧急会议
- 暂停所有其他工作
- 快速定位和修复
- 紧急发布hotfix

### P1 - 高（High）

**定义：** 重要功能异常，影响大量用户或核心业务流程

**示例：**
- 活动创建功能失败
- 数据统计显示错误
- 支付功能异常
- 重要API接口500错误

**处理时效：** 1个工作日内修复

**处理方式：**
- 优先处理，调整当前迭代计划
- 快速修复并测试
- 随下一个版本发布或紧急发布

### P2 - 中（Medium）

**定义：** 次要功能异常，影响部分用户或有替代方案

**示例：**
- 导出功能偶尔失败
- UI显示小问题
- 非核心功能异常
- 性能轻微下降

**处理时效：** 3个工作日内修复

**处理方式：**
- 纳入当前迭代
- 正常修复和测试流程
- 随下一个版本发布

### P3 - 低（Low）

**定义：** 边缘场景问题、优化建议、不影响功能使用

**示例：**
- UI文案错误
- 边缘场景的小问题
- 性能优化建议
- 代码重构建议

**处理时效：** 下个迭代处理

**处理方式：**
- 加入产品待办列表
- 根据优先级排期
- 可能与其他功能一起发布

## 影响范围评估

### 用户影响

- **所有用户**：严重程度提升一级
- **大部分用户（>50%）**：严重程度提升
- **部分用户（10-50%）**：正常评估
- **少数用户（<10%）**：严重程度降低

### 业务影响

- **核心业务流程中断**：P0或P1
- **重要业务功能受损**：P1或P2
- **次要功能受影响**：P2或P3
- **不影响业务**：P3

### 数据影响

- **数据丢失或损坏**：P0
- **数据不一致**：P1
- **数据显示错误**：P2
- **数据格式问题**：P3

## 快速评估决策树

```
是否导致系统崩溃或数据丢失？
├─ 是 → P0
└─ 否 → 是否影响核心功能？
    ├─ 是 → 是否影响所有用户？
    │   ├─ 是 → P1
    │   └─ 否 → P2
    └─ 否 → 是否有替代方案？
        ├─ 是 → P3
        └─ 否 → P2
```
