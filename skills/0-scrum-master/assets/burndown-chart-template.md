# 燃尽图模板

## 模板说明
燃尽图（Burndown Chart）是敏捷团队用于可视化迭代进度的工具，展示剩余工作量随时间的变化趋势。

## 使用场景
- 每日站会后更新
- 团队随时查看进度
- 识别进度偏差和风险
- 迭代评审时回顾

- **迭代周期：** [开始日期] - [结束日期]

### 计算公式

**理想剩余：**
```
理想剩余 = 承诺故事点 - (承诺故事点 / 迭代天数 × 当前天数)
```

**实际剩余：**
```
实际剩余 = 承诺故事点 - 累计完成故事点
```

**偏差：**
```
偏差 = 实际剩余 - 理想剩余
正值表示落后于计划，负值表示超前于计划
```

## 使用说明

### 如何更新燃尽图

**每日站会后：**
1. 统计当日完成的故事点
2. 计算累计完成和实际剩余
3. 更新燃尽图数据表
4. 分析偏差和趋势
5. 识别风险并采取措施

### 如何解读燃尽图

**理想情况：**
- 实际线跟随理想线下降
- 最后一天到达0点

**常见模式：**

1. **平缓开始（Flat Start）**
   - 前几天实际线平坦
   - 原因：任务启动慢、环境问题
   - 应对：识别障碍，加速启动

2. **陡峭下降（Steep Drop）**
   - 某天突然大幅下降
   - 原因：大故事完成、批量验收
   - 注意：确认质量没有问题

3. **上升（Scope Increase）**
   - 实际线向上
   - 原因：新增工作、范围变更
   - 应对：与PO协商，调整范围

4. **平台期（Plateau）**
   - 实际线长时间不变
   - 原因：障碍阻塞、等待依赖
   - 应对：移除障碍，调整任务

### 责任人
- **Scrum Master：** 每日更新燃尽图，分析趋势
- **团队成员：** 及时更新任务完成状态
- **Product Owner：** 关注进度，必要时调整范围

## 注意事项
- ✅ 每日更新，保持数据准确
- ✅ 关注趋势，而非单日波动
- ✅ 及早识别风险，主动应对
- ✅ 范围变更要记录并调整理想线
- ✅ 结合每日站会讨论进度
- ✅ 不要为了好看的图表而妥协质量
- ✅ 燃尽图是工具，不是目的

### Excel公式参考

**理想剩余（B列）：**
```excel
=承诺故事点 - (承诺故事点 / 迭代天数 * (ROW()-2))
```

**偏差（G列）：**
```excel
=实际剩余 - 理想剩余
```

**日均速率（H列）：**
```excel
=累计完成 / (ROW()-2)
```
