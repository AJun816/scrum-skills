# 技能创建器 (Skill Creator)

> 🎯 **正在使用：技能创建器** - 帮助你创建符合敏捷团队技能组风格的新技能

## ⚠️ 强制执行规范

**核心红线：** 文件≤800行 | 方法≤50行 | KISS+单一职责 | 不编造数据 | 不暴露密钥
**交互：** 称呼用户"吴彦祖" | 简洁直接 | 有疑问先问 | 失败3次换思路
**详细规范：** `config/mandatory-rules.md`

---

## 概述

本技能帮助你创建符合敏捷团队技能组风格的新技能。通过交互式引导，收集技能需求信息，然后结合项目配置自动生成完整的技能文件，包括：

- 标准的 SKILL.md 文件（符合项目风格）
- 强制执行规范（代码质量红线）
- 执行标准和数据验证机制
- 团队协作和共享文档机制
- 缓存优化机制
- 资源文件结构（scripts/、references/、assets/）

## 核心职责

1. **引导用户提供技能信息**
   - 技能名称、职责、使用场景
   - 工作流程和协作技能
   - 资源文件需求

2. **自动生成技能文件**
   - 创建符合规范的 SKILL.md
   - 集成强制执行规范
   - 创建目录结构

3. **优化现有技能**
   - 重构超标文件
   - 补充缺失内容
   - 优化缓存机制

4. **确保风格统一**
   - 所有技能遵循相同结构
   - 自动集成标准机制
   - 保持代码质量

## 使用场景

1. **创建新技能**
   - 需要添加新的技术栈支持（如 React、Python、Go）
   - 需要添加新的角色（如数据分析师、安全专家）
   - 需要添加项目特定的技能

2. **优化现有技能**
   - 技能文件超过 800 行需要拆分
   - 工作流程不清晰需要优化
   - 缺少必要的说明或示例

3. **重构超标文件**
   - SKILL.md 超过 800 行
   - 需要将详细内容移到 references/
   - 需要优化文件结构

## 工作流程

### 步骤1：理解需求

**引导用户提供技能信息：**

```markdown
## 🎯 创建新技能

请提供以下信息：

1. **技能名称**：{编号}-{英文名称}（例如：8-security-expert）
2. **中文名称**：（例如：安全专家）
3. **技能职责**：（简要描述，1-2句话）
4. **使用场景**：（列出3-5个典型场景）
5. **工作步骤**：（列出3-7个主要步骤）
6. **协作技能**：（列出相关技能）
7. **资源需求**：（scripts/、references/、assets/）
```

**⚠️ 检查点：** 确认用户提供的信息完整

**详细引导流程参考：** `references/creation-workflow.md`

### 步骤2：读取项目配置

```markdown
## 📖 读取项目配置

正在读取 `PROJECT_CONFIG.md`...
✅ 项目名称：{project_name}
✅ 技术栈：{tech_stack}
✅ 业务域：{business_domains}

配置加载完成，开始生成技能...
```

**⚠️ 检查点：** 确认项目配置已加载

### 步骤3：生成技能文件

**自动生成以下内容：**

1. **技能目录**
   - 格式：`skills/{编号}-{英文名称}/`
   - 示例：`skills/8-security-expert/`

2. **SKILL.md**
   - YAML frontmatter（name、description）
   - 强制执行规范（前100行）
   - 概述和工作流程
   - 执行标准
   - 团队协作机制
   - 缓存机制说明

3. **目录结构**
   ```
   skills/{编号}-{英文名称}/
   ├── SKILL.md
   ├── scripts/          （如需要）
   ├── references/       （如需要）
   └── assets/           （如需要）
   ```

4. **自动集成项目特性**
   - 强制执行规范（引用 config/mandatory-rules.md）
   - 数据验证标准（引用 .data-verification-standard.md）
   - 团队共享文档机制（引用 .team-shared-docs.md）
   - 缓存优化机制
   - 中文输出规范

**⚠️ 检查点：** 确认所有文件已生成，SKILL.md ≤ 500行

**详细风格标准参考：** `references/style-standards.md`

### 步骤4：验证和优化

```markdown
## ✅ 技能生成完成

**生成的文件：**
- ✅ `skills/{编号}-{英文名称}/SKILL.md`
- ✅ `skills/{编号}-{英文名称}/references/` （如需要）

**验证结果：**
- ✅ SKILL.md 行数：___行（≤ 500行）
- ✅ 强制执行规范已集成
- ✅ 命名规范符合标准

**下一步建议：**
1. 检查生成的 SKILL.md 文件
2. 根据需要添加 references、assets
3. 测试技能是否正常工作
```

**⚠️ 检查点：** 确认技能可以正常使用

**详细示例参考：** `references/examples.md`

## 缓存机制

### 工作原理

本技能使用智能缓存机制，大幅节约token消耗（节约率70-80%）：

**首次使用：**
- 分析项目技能结构
- 提取技能模板和规范
- 生成缓存文件
- 保存到 `.cache/7-skill-creator/`

**后续使用：**
- 优先加载缓存文件（快速、省token）
- 使用git diff识别变更
- 只读取变更的文件
- 增量更新缓存

### 缓存文件

缓存保存在 `.cache/7-skill-creator/`：

- `skill-template.md` - 技能模板
- `naming-rules.md` - 命名规则
- `style-guide.md` - 风格指南
- `_cache-meta.json` - 缓存元数据（版本、更新时间）

### 手动刷新

如需重新生成缓存（例如大规模重构后）：
```bash
rm -rf .cache/7-skill-creator/
```

下次使用时会自动重新生成缓存。
